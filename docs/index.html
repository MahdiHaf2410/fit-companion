Questions

Is it free?

Yes. The app, the cloud backup and the AI features are free (with fair daily limits for AI).

Is my data private?

Everything is stored on your phone. The optional cloud account is protected so only you can read your data, and friends only see a few public stats.

Which phones are supported?

Android 8.0 and newer. There is no iPhone version yet.

Does it work without internet?

Yes. Workouts, food logging and progress work offline. AI, videos, barcode lookup and cloud sync need internet.

Android says the app is unknown. Is it safe?

The app is installed from outside the Play Store, so Android warns you. The source code is public on GitHub.
